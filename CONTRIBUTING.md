# Contributing

Open a GitHub issue with a primary publication or official documentation, access route, evidence status and limitation. For corrections, cite the row ID, field, proposed change and source. Broken links and new evaluations are welcome. Pull requests should edit `data/tools.csv` (and `data/candidates_reviewed.csv` for unresolved candidates), then run `Rscript R/render_site.R`. Do not manually edit generated `docs/`. The maintainer checks evidence and updates `CHANGELOG.md` before merge. An automated flag cannot establish misconduct; avoid identifying individuals as culpable.
