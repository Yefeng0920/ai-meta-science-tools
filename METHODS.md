# Curation methodology

This is a curated, selective directory, not a systematic review or census. Initial leads came from the companion Perspective and targeted searches for original publications, official sites and developer repositories through 27 October 2026. Searches considered statistical checking, image screening, claim verification, agentic meta-research, executable papers and reproduction benchmarks. Candidates were included only when their identity, function and primary technical or official source were identifiable. Unresolved leads are in `data/candidates_reviewed.csv`.

Categories: **statistical and methodological checking**; **research integrity and publication screening**; **agentic meta-research**; **scientific claim and manuscript verification**; **computational reproducibility and executable research**; **evaluation benchmarks**. Metadata infrastructure is included only where directly useful to checking the scientific record. General chatbots, ordinary search engines and discovery-only AI scientists are excluded.

An **automated tool** executes a narrow check; **AI-assisted** means model output assists a human decision; **agentic** means multiple coordinated steps or tool calls toward an evaluative task. Initiatives and benchmarks are labeled separately. None of these labels establishes fully autonomous trustworthy meta-science.

Each row was checked against at least one publisher publication, official project site or developer repository. `evidence_class` describes the strongest cited evaluation or documentation available during curation; a peer-reviewed system paper does not independently validate every claim. Commercial product descriptions are attributed to developers. Access, deployment, maintenance, independent performance and links may change. No live HTTP link test or independent hands-on performance replication was completed in this candidate release. Unknowns are explicit. A paper alone is not evidence of public service access.

Propose changes using an issue or pull request with a primary source, exact field changes, date and evidence classification. Maintainers review identity, fit, access, claims and limitations, then update the CSV and changelog. Periodic link checks can detect failures but never substitute for scientific re-verification. Human review is required before allegations or consequential use.
